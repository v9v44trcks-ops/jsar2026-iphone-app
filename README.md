# JSAR 2026 iPhone演題メモ

第39回日本腹部放射線学会の演題メモ用iPhone版PWAです。

## 使い方

1. このフォルダをGitHub Pagesで公開します。
2. iPhoneのSafariで公開URLを開きます。
3. Safariの共有ボタンから「ホーム画面に追加」を押します。

## 機能

- 口演・ポスター・クイズ検索
- 気になるチェック
- 疾患概念 / 画像所見 / 病理所見 / その他のメモ
- 用語集
- 文献メモ
- Markdown書き出し
- JSONバックアップ/復元

## 注意

メモはiPhone内のブラウザ保存領域に保存されます。Mac版とは自動同期しません。
バックアップはアプリ内の「バックアップ」からJSONで保存してください。
