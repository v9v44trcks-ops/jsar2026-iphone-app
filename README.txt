JSAR 2026 iPhone単独版

これはiPhone内にメモを保存する版です。
Mac版とは自動同期しません。

使える機能:
- 口演・ポスター・クイズ検索
- 気になるチェック
- 疾患概念 / 画像所見 / 病理所見 / その他のメモ
- 用語集
- 文献メモ
- Markdown書き出し
- JSONバックアップ/復元

ホーム画面アプリとして使うには:
1. iphone-app フォルダをHTTPSで見られる場所に置く
   例: GitHub Pages, Netlify, 自院内サーバーなど
2. iPhoneのSafariで index.html を開く
3. 共有ボタン → ホーム画面に追加

一度読み込むと、基本画面はオフラインでも開けます。
文献リンクを開くときだけインターネット接続が必要です。
